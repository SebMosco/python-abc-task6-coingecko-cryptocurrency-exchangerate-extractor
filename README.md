[Основание](https://osnovanie.info/)

# Функции
Программа на языке Python для демонстрации курсов криптовалют на сайте https://www.coingecko.com/

# Инструкция по использованию
При запуске программа считывает перечень доступных криптовалют и их текущие курсы  с сайта https://www.coingecko.com/
Пользователь выбирает три криптовалюты.
После выбора трех криптовалют активируется кнопка [Получить курс обмена].
Появляется отчет с курсаи криптовалют по отношению к доллару США.
